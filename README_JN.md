# JN Study Branch
- 개인 작업 브랜치: JN

## 예방접종 이력관리 기반 헬스케어 체크리스트 대시보드

### 프로젝트 개요
사용자가 예방접종 상태를 선택하고,
예방접종 후 증상에 대해 AI 기반 안내를 받을 수 있는 웹 서비스입니다.
프론트엔드(UI)와 FastAPI 백엔드를 분리하여 구성하였으며,
OpenAI API를 활용해 실제 LLM 기반 증상 안내 기능을 구현했습니다.

### 사용 기술
- Frontend: HTML, CSS, JavaScript
- Backend: FastAPI, Pydantic
- AI / LLM: OpenAI API
- 기타: REST API, CORS, 환경 변수 관리(.env)

### 주요 기능
- 예방접종 항목별 상태 선택
- 종합 예방접종 상태 자동 계산
- 상태에 따른 색상 아이콘 표시
- 의료 서비스 톤의 안내 문구 제공
- LLM 기반 예방접종 후 증상·부작용 안내
- 보안 설정 : OpenAI API Key는 .env 파일로 분리 관리 /
           .gitignore를 통해 환경 변수, 서버 파일 GitHub 업로드 제외

### LLM 기반 예방접종 후 증상 안내
사용자가 예방접종 종류와 접종 후 나타난 증상을 입력하면  
LLM을 활용하여 일반적인 이상 반응인지, 경과 관찰이 필요한 상황인지,  
의료기관 방문이 권장되는 상황인지를 의료 서비스 톤으로 안내합니다.

- 예방접종 종류 선택 (코로나19, 인플루엔자, 파상풍, B형간염)
- 접종 후 증상 자유 입력
- FastAPI 기반 백엔드 서버를 통해 LLM 응답 제공
- 응급 상황 시 의료기관 방문 권고 문구 포함

### 주의사항
본 서비스는 예방접종 정보 제공을 위한 참고용 서비스이며  
의료 전문가의 진단이나 처방을 대체하지 않습니다.  
증상이 심하거나 지속될 경우 반드시 의료기관을 방문하시기 바랍니다.
